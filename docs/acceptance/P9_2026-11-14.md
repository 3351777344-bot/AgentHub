## 边界

浏览器用公开合成内容调用真实 DeepSeek Flash 与百炼 Flash，并通过真实 MCP SDK 执行本地乘法。审批用管理员将隔离环境的无副作用乘法工具登记为高风险以触发工作流。P7 集成回归另用真实 HTTPS MCP 测试服务执行有副作用的写标记案例。浏览器文档链路使用 TXT，文本 PDF 和 Markdown 解析由既有回归覆盖。生产规模、其他浏览器和辅助技术矩阵、服务级集中日志、长期保留、上线安全与备份恢复属于后续验收。业务库故障演练和升级不在本次范围。

验收项目服务已停止。Compose 命名卷按范围保留，回归数据库使用容器临时文件系统。最终并行停止整栈时，三个 worker 容器退出码为 137，API、MCP、PostgreSQL、Redis 为 0。P10 需用依赖仍在线的分步停机复验 worker 优雅退出，确认超时和退出原因。
