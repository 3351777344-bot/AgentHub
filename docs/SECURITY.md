# AgentHub 身份与权限边界

最后更新：2026-11-12。当前为本地单组织开发栈，已实现基础身份、知识库、RAG 与工具权限。

## P6 工具与 MCP 信任边界

- 只有管理员可登记部署方配置的服务键、发现工具、固定版本和停用配置。成员只可调用被授权的版本，`knowledge_search` 使用认证身份并沿用知识库所有权。写入和高副作用版本保持关闭，服务端显式写入/破坏提示也会拦截只读登记。人工审核负责确认可信服务的实际行为。
- 本地 MCP 以 UID 999 运行，禁用容器网络，移除所有 capabilities，启用 `no-new-privileges`，根文件系统只读。唯一的可写业务挂载是 Unix socket 卷，API 只读挂载。服务没有平台密钥、文档卷、主机目录或 Docker socket。
- 远端只接受部署方固定的 HTTPS URL、端口、路径和公网单播 IPv4，测试环境另允许回环 IPv4。实际 TCP 直连固定 IP，TLS 验证使用原主机名，环境代理关闭，重定向拒绝。URL 禁止内嵌凭据、查询和片段。目标变更触发重新登记。
- 认证模式为匿名或固定目标专用 Bearer。令牌按服务键从独立配置映射取出，只有该目标请求携带它；平台会话令牌始终留在 API。当前未接入 OAuth、旧版 MCP 或任意动态服务发现。
- MCP 工具需有 JSON Schema 2020-12 对象输入/输出，校验离线。发现阶段跳过缺少结构化输出或使用引用、正则、`x-mcp-header` 等未支持关键字的定义。限制目录页数、工具数量、请求和返回字节以及远端时限。服务端内容及 schema 说明均当作数据处理。
- 执行审计仅保留调用者、请求 ID、登记版本、服务键、状态、耗时与稳定错误码。入参、检索内容、结果、令牌与上游原始错误不进入调用审计。停用后新的调用被拒绝，已经开始的调用可能仍完成。超时会记录失败，进程中断可能留下 `started`，两种情况下都要另行核对服务方是否执行。

部署边界和局限参见 [MCP 安全最佳实践](https://modelcontextprotocol.io/docs/tutorials/security/security_best_practices) 与 [验收记录](acceptance/P6_2026-11-12.md)。

## P5 在线检索与问答边界

搜索和问答均先校验 Bearer 与知识库所有权，问答另校验会话所有权。向量 SQL 约束知识库 ID、用户 ID、可见状态、文档版本和模型空间。管理员遵循同一所有权规则。RAG 历史只向所属会话的用户开放。

问题发送给百炼 Embedding。选中的分块正文与问题发送给 DeepSeek。仅使用公开或脱敏数据。系统提示明确把资料视为不可信数据，生成请求不携带工具。服务端校验引用 ID 是否属于本轮上下文。语义上的证据支持仍需用评测和原文核对。

收尾时在知识库行锁内复查模型收到的全部分块。已删除来源会阻止新答案提交，历史引用标为不可用。SSE 草稿可能已发送给发起请求的用户，客户端收到错误或断连时应丢弃。删除无法撤回此前传输的内容，也不会清除已完成会话中的答案文本。

## P4 知识库与原文边界

知识库严格私有，管理员没有读取他人知识库的隐含权限；所有文档/原文/任务/分块操作先校验KB归属，越权统一404。worker在批次和发布时检查资源墓碑、版本、租约、固定模型空间及用户是否仍激活。已开始的读取或第三方HTTP请求不能被事后禁用/删除撤回。

用户文件名仅用于展示，拒绝路径/控制字符，磁盘名由UUID生成；仅支持txt/md/pdf，实际内容由UTF-8或PDF解析检查。ASGI限制真实body字节后才允许multipart暂存；文件、页数、字符和分块均有上限。原文下载采用attachment和nosniff，不在浏览器内执行Markdown/PDF内容。没有病毒扫描、OCR或完整恶意PDF沙箱；子进程超时/解码限制与worker容器资源上限只是当前本地防护。

Embedding会发送分块原文到配置的百炼北京端点，当前只允许公开/脱敏资料；没有自动脱敏或敏感内容识别器。API上传不是第三方零留存承诺。数据库本地存向量不改变云端原文出域；删除不保证撤销在途调用或供应商已接收数据。日志不包含原文、文件名、向量、密钥及供应商原始错误，任务仅返回稳定错误码与已知用量，无自动金额配额。

逻辑删除事务立即移除分块、隐藏文档、取消未完成任务；物理文件由worker重试清理，离线时仍占卷空间。墓碑/任务历史尚无保留清理机制，备份也可能保留已删原文。生产数据删除、审计、保留和恢复治理需P10单独验证。


## 身份认证

- 新用户密码 12—128 字符、不能全为空白；不 trim 密码。Argon2id 使用随机盐，参数 time=3、memory=65536 KiB、parallelism=4；登录发现旧参数时重新哈希。
- 用户名先去除首尾空格并转小写，再校验 3—64 位 ASCII 字母/数字/下划线/点/连字符，首位限字母/数字/下划线。数据库还有唯一约束与 CHECK 防止绕过 API。
- 登录创建 32 随机字节的 URL-safe Bearer 令牌。原始令牌仅在成功登录响应出现，数据库只保存 SHA-256 摘要；不把密码或令牌写入审计和应用日志。
- 默认绝对有效期 3600 秒，配置范围 60—86400 秒；无滑动续期、刷新令牌或 JWT。每次请求查询会话、数据库时间、用户状态和当前角色。
- `Authorization: Bearer <token>` 是唯一认证载体；不接受 URL 查询参数，也不自动设置认证 Cookie。所有 `/api/v1/` 响应（包括错误）设置 `Cache-Control: no-store`。
- 未知用户仍验证 dummy Argon2 哈希；错误密码、未知和禁用账号均返回相同 401。此措施只降低明显时间差，不宣称实现恒定时间 HTTP 响应。

## 初始化、退出与失效

首次管理员仅通过本地受控 CLI 创建，密码隐藏输入；无公开注册、默认管理员或默认口令。初始化在角色行锁内检查整个用户表为空，并发初始化只有一个成功；已有用户时拒绝覆盖。

```powershell
docker compose exec api /app/.venv/bin/python -m agenthub.identity.cli init-admin --username admin
```

`--password-stdin` 供受控自动化输入一行密码，不提供命令行密码参数。不要把真实密码写进终端命令、源码、文档、测试或 Git。本轮本地开发库尚未设置管理员密码，需由用户自行运行上述命令。

退出只撤销当前令牌。修改密码撤销该用户全部令牌（包括当前令牌），需重新登录。管理员变更角色/启停状态也撤销该用户全部已有会话；重新启用不会恢复旧令牌。已过期、已撤销、随机或格式不合法令牌统一 401。重复退出也为 401。

## 授权矩阵与资源边界

| 操作 | 未登录 | member | admin |
| --- | --- | --- | --- |
| 健康接口、登录、交互文档 | 允许 | 允许 | 允许 |
| 查看自己、退出、修改自己的密码 | 401 | 允许 | 允许 |
| 读取 `/users/{id}` | 401 | 仅自己；其他 ID 均 403 | 任意已存在用户 |
| 用户列表、创建用户、审计列表 | 401 | 403 | 允许 |
| 变更用户角色/状态 | 401 | 403 | 仅其他用户；修改自己返回 409 |

当前会话和知识库均为私有资源，管理员也须通过所有权检查。共享权限与 Agent 运行归属将在对应模块中显式建模。

`roles.admin` 行锁串行化管理写操作，并在获取锁后重新验证身份；禁止管理员修改自己的角色/状态，防止最后一位管理员误禁用自己。退出/禁用不主动中断已认证的在途只读请求，也不等于撤销外部工具已发生的副作用。

## 审计与错误

记录 `user.created`（含 bootstrap）、`user.updated`、`auth.login`、`auth.login_failed`、`auth.logout`、`auth.password_changed`、管理角色校验的 `authorization.denied`。保存操作者、目标、事件名、请求 ID、时间。登录失败不保存输入用户名/密码。并非每个 HTTP 失败都有审计；所有请求另有脱敏请求日志。

管理变更和审计在同一数据库事务提交，审计失败则管理操作失败且回滚。审计只读 API 仅管理员可读；数据库高权限账号仍能修改审计，不宣称防篡改。当前不保存字段差异、IP 或完整请求，后续按治理需要扩展。

数据库连接/池超时返回脱敏 503；其他意外异常返回统一 500。响应不暴露 SQL、连接口令、原始验证输入或堆栈。401 带 `WWW-Authenticate: Bearer`；错误契约见 [API 文档](API_DESIGN.md)。

## 部署与已知限制

API 仅绑定本机回环；PostgreSQL/Redis 仅内部网络。`.env` 被 Git/Docker build 忽略；SecretStr 保护表示形式而非加密，禁止打印解密值和完整 Compose 配置。数据库仍使用本地初始化账号，Redis 尚无密码。

当前未实现登录限流/暴力破解防护、MFA、密码找回、管理员重置密码、会话清理/并发上限、平台入口 TLS、SSO、多租户、受控审计导出和备份恢复。前端令牌存储策略在 P9 确认。P7 负责审批与外部副作用恢复，P10 负责部署治理和容量验证。

设计依据：[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[OWASP Session Management](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)、[argon2-cffi API](https://argon2-cffi.readthedocs.io/en/stable/api.html)。依据在 2026-11-10 复核；实现取舍见 ADR-009/010。

P3 模型地址只能由受控环境变量配置，API 不接受调用方自定义 URL；禁用重定向和环境代理自动继承，密钥仅向所配置服务发送。HTTP 仅供受信任本地服务，远程服务应配置 HTTPS。兼容服务可不要求密钥；是否允许发送聊天数据和实际预算由用户确认后才做真实调用。P3 尚无调用频率/金额限额，仅输出 token、上下文字符和请求总时限保护；仅适用于当前本地边界。
