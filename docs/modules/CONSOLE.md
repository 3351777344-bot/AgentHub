# P9 控制台与第十课

入口为 [本地控制台](http://127.0.0.1:8000/)。FastAPI 从已安装的 `agenthub.web` 包提供 HTML 和静态资源。页面直接使用 [现有 API](../API_DESIGN.md)，任务仍由知识库、Agent 和评测 worker 独立执行。使用同一套 [Compose 启动流程](../DEPLOYMENT.md#p9-控制台)。

## 使用路径

| 页面 | 可以完成的操作 |
| --- | --- |
| 工作台与用户管理 | 登录、退出、改密。管理员创建成员、调整角色与启用状态，查看身份审计 |
| 知识库与对话 | 新建知识库、上传三类文本文件、查看任务状态和已完成批次、失败后创建重试版本、查看片段或下载原文。会话可选普通聊天或指定知识库的 RAG，引用连接到源片段 |
| Agent | 新建或编辑模型、提示词、知识库、工具版本和执行预算，选择是否把答案写入自己的会话。查看事件与步骤、暂停、恢复、取消和按调用参数审批 |
| 工具与 MCP | 查看参数与结果约束并执行只读工具。管理员登记部署端预设的服务键、发现工具、复核定义摘要、登记版本、启停服务或工具及 Agent 执行权限 |
| 评测 | 创建人工复核的数据集版本、选择 RAG 金标片段或预期 Agent 工具、发起与取消批次，查看逐条结果、指标、人工复核及基线/候选差异 |
| 运行日志 | 按请求 ID 查自己的工具调用，导航至入库任务、Agent 步骤与评测结果。管理员可看身份审计。部署进程日志通过 Compose CLI 查看 |

## 实现与设计

- `app.js` 登记路由和页面职责。登录请求换取 Bearer 会话，再读取 `/auth/me` 判断可见入口。路由切换中止旧页面的异步读操作。后端校验令牌、角色、所有权与审批条件。
- `api.js` 将令牌放在模块内存并通过 Authorization 头发送。静态资源和 API 同源。错误通知展示后台公开错误码和请求 ID。会话失效会清除页面数据并返回登录。
- `sse.js` 将响应字节连续解码，按空行交付 SSE 事件。聊天采用带 Bearer 的 POST，`delta` 更新临时文本，`done` 后重新读取消息。断开后保留输入并回查历史，供用户决定是否重新提交。
- `knowledge.js` 和 `evaluations.js` 间隔约两秒查询活动任务。任务结束后停止轮询。评测报告按后台终态读取。状态和进度来自 HTTP 响应。
- `agents.js` 决定哪些动作可尝试、显示版本化步骤、按 `Last-Event-ID` 从已收到的最后一条事件重连。暂停和待审批可使服务主动关闭 SSE。收到操作结果后重查状态，并在拒绝或批准时回送该次调用摘要。
- `tools.js` 将远端描述、输入和输出约束按纯文本呈现。登记时服务端重新发现并核对摘要。Agent 配置用 `for_agent=true` 列出已启用的版本，最终选择仍经执行器校验。
- `management.js` 汇总已有审计和资源入口。各条记录保留可用的运行 ID、请求 ID 或调用 ID；平台级跨进程聚合属于 P10。

原生模块可直接对应每组 API，部署只需要现有镜像与浏览器。React 或 Vue 能为更大的界面提供组件、状态管理和复用；以服务端模板配合局部 JavaScript 也可以实现常规表单，但流式响应、光标重放与任务刷新仍需要浏览器处理。当前方案要求模块作者统一处理销毁、焦点和异步状态。控制台使用系统字体，同源资源策略和 DOM 文本节点。

## 常见错误与面试方向

把收到 `delta` 当成保存成功，会漏掉最终写库失败。忽略 SSE 跨网络块的完整事件边界，可能破坏中文字符和事件 JSON。根据浏览器超时自动重发 POST，可能创建重复任务或再次调用付费服务。菜单可见性适合导航，权限检查必须覆盖直接 API。在事件退出时比较持久游标，可避免终态先到、最后几条事件还没读到的竞态。面试中可以用这些例子说明流式推送、状态轮询、异步动作的幂等边界及端到端测试如何确认实际结果。

## 练习

1. `chat.js` 何时显示模型输出，何时认为消息已写入历史？浏览器在两者之间断开会怎样？
2. `agents.js` 中，等待审批与非预期 SSE 中断会触发哪些不同的后续操作？服务端为什么还要校验调用摘要？
3. 如果成员手动输入用户管理路由或请求 API，会分别看到什么？各由哪层决定？

代码练习：在 `knowledge.js` 的任务卡给最后一次失败展示中文操作提示，保留原错误码和请求 ID。用无效 UTF-8 的 TXT 和一次手动重试验证。

项目思考：如果 P10 要跨浏览器刷新恢复 Agent 的事件查看，哪些信息应放进路由、哪些应重新读取服务端、哪些不能写入浏览器持久存储？
